# 答案くみたて

憲法・民法総論・刑法総論の短い事例を読み、答案の4つの段（問題提起 → 規範 → あてはめ → 結論）を札から選んで組み立てる、1日5問の学習ゲームです。

遊ぶ: <https://satou-aaaaa.github.io/toan-kumitate/>

## 遊び方

- 今日の5問（やさしい2・ふつう2・むずかしい1）は日付で決まり、だれでも同じ問題です。上級（むずかしい3問・ヒントなし）、練習（科目・難しさ・論点ごと）、とことん（好きなだけ）もあります。
- 段ごとに札を1つ選びます。まちがえても続けられ、ヒントは段ごとに2回まで。組み終えると、規範の出どころ（条文・判例）と、なぜそうなるかが出ます。
- 記録は遊ぶ人のブラウザ（localStorage）にだけ残ります。外へ送りません。

## 中身について

- 規範は条文（e-Gov 法令検索）と最高裁判所の判例（裁判所ウェブサイトの裁判例）で確かめたものだけを使っています。条文の言葉は `node tools/check-laws.mjs` で e-Gov と照らします。
- 学説が分かれる所は、判例の立場によっています。
- 事例の人・会社はすべて架空です。
- これは学習用のゲームで、法律の相談には使えません。困ったときは法テラス（<https://www.houterasu.or.jp/>）や弁護士に相談してください。

## 作り方

`index.html`（画面）と `data.js`（論点と問題の作り方）だけで動きます。検査は `node qa/run.mjs`。
